簡報 + 錄音 → 影片

把一份 PDF 簡報和一整段錄音，在瀏覽器裡合成影片（WebM）。檔案完全不上傳，全部在你的電腦本機處理。建議用 Chrome / Edge。

1 · 載入檔案 2 · 邊聽邊點換頁 3 · 輸出影片

1 · 載入 PDF 與錄音

📄 拖入或點選 PDF 簡報
🎙️ 拖入或點選 錄音檔（mp3 / m4a / wav…）

2 · 邊聽邊點換頁

播放錄音，每當你要「換到下一頁」時就按一下 下一頁（或按 Enter）。共有 – 頁，需要按 – 次換頁。

微調每頁開始時間（可手動編輯，單位秒）
頁開始時間 (秒)= 時間碼

3 · 輸出影片

兩種輸出方式：
🅐 瀏覽器即時錄製 WebM（下方）——不用裝任何東西，但 N 分鐘錄音要花約 N 分鐘錄。
🅑 本機快速壓 MP4（推薦）——按下面「⬇ 匯出時間表 JSON」，再跑 python make_video.py 簡報.pdf 錄音檔 timeline.json，用 ffmpeg 秒出 MP4。

🅐 以下是「即時錄製」：會實際播放整段錄音一次來錄影，所以 N 分鐘的錄音就要花約 N 分鐘。錄製過程請保持此分頁在前景、不要切走。
